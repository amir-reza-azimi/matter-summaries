October 9, 2026 — Composer predictions in Codex

Codex now has a beta Composer predictions feature that suggests the next message in the current thread after Codex responds. Pressing Tab accepts a suggestion into the composer, where it can still be reviewed or edited; it is never sent automatically.

For eligible personal ChatGPT Pro users, it is available in the latest Codex desktop app for local and SSH threads using GPT-6 Astra or GPT-6.1 Sol. Predictions are enabled by default but can be disabled in General settings. During the beta, suggestions themselves do not consume Codex usage or credits, though a message eventually sent still uses normal limits. This matters because it reduces the friction of steering an active desktop coding task while preserving human control over the final instruction.
