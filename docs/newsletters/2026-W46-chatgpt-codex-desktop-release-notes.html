ChatGPT & Codex Desktop Release Notes · 2026-W46

Week: 2026-W46 · Window: October 13–November 13, 2026

October 26, 2026 — GPT-6.1 Terra arrives in Work and Codex

GPT-6.1 Terra is now available in ChatGPT Work and Codex for Plus, Pro, Business, Enterprise, and Edu plans. OpenAI describes it as a fast, efficient professional model that combines strong image understanding with precise computer use. It can reason about images and screens, then act across a browser, the desktop, and connected apps.

On desktop, choose Terra from the Advanced model list in the ChatGPT app. Availability can still depend on workspace and administrator controls, and the model is not offered in Chat. This is the most consequential desktop update in the catch-up window because it adds a lower-cost model specifically suited to visual checks and computer-use workflows.

October 14, 2026 — GPT-5.5 retires from Codex

GPT-5.5 retired from Codex for sessions signed in with ChatGPT. OpenAI recommends GPT-6.1 Sol when that model is available to the user’s plan and client. API-key Codex sessions and the OpenAI API are not affected by this retirement.

Desktop users should update saved model choices, workspace defaults, custom agents, scheduled tasks, and scripts that still select GPT-5.5. Existing automation can otherwise fail at model selection even when the surrounding workflow is healthy.
