September 17, 2026 · Connect multiple accounts to plugins in ChatGPT

ChatGPT now supports connecting multiple accounts to plugins, expanding the earlier multi-account support beyond Gmail, Google Calendar, and Google Contacts. The update is available across web, mobile, and desktop. This matters because desktop workflows can draw on separate personal and work accounts in the same conversation, while each connection should still be reviewed and authorized deliberately.
