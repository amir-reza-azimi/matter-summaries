ChatGPT & Codex Desktop Release Notes · 2026-W38

Week: 2026-W38 · Window: 2026-08-20 to 2026-09-14

Five material desktop changes were published in the initial 30-day lookback. The common thread is that the current desktop experience is becoming more capable at working with browser context, connected accounts, local context, and new operating systems.

September 1, 2026 · Use website tools in the desktop browser

ChatGPT Work and Codex can discover and use supported website tools in the desktop app’s built-in browser through WebMCP. This matters because website-native tools can be used from a desktop task without a separate connection, while existing sensitive-action confirmations remain in place.

August 28, 2026 · Connect multiple Google accounts to ChatGPT

ChatGPT can connect multiple Gmail, Calendar, and Contacts accounts across desktop as well as web and mobile. This matters for desktop work that spans personal and work contexts, provided each connected account has been intentionally authorized.

August 20, 2026 · Codex and ChatGPT feature updates

On Apple silicon Macs, the Apple Messages plugin in the ChatGPT desktop app can read, search, prepare, and, with approval, send Messages content. The same release also made Computer History available in the EEA, Switzerland, and UK for eligible Pro users on macOS, and added portable read-only Codex chat snapshots. These changes make the desktop app more useful for local-context work, but the Messages and history features need deliberate privacy review.

August 14, 2026 · Linux desktop public preview

ChatGPT and Codex desktop are now available in public preview on specified Ubuntu, Debian, and Fedora releases. The Linux app supports browser actions in its built-in browser and Chrome, but does not yet control other desktop apps, making that boundary important when planning Linux automations.

August 13, 2026 · Computer History for macOS

Computer History is an optional macOS feature that lets ChatGPT and Codex reference selected app and website activity. It is off by default, records interaction events rather than screenshots or audio, and can be paused, scoped, inspected, or deleted, so it is useful only where that privacy tradeoff is intentional.
