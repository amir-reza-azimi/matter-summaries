ChatGPT & Codex Desktop Release Notes · 2026-W40

Week: 2026-W40 · Window: September 29–October 5, 2026

What changed

September 29 · Codex Cloud. Codex tasks can start or continue from desktop using reusable cloud environments, isolated workspaces, and cloud execution that continues while the computer sleeps. This matters when a desktop task should outlive the local machine without losing its repository setup.

September 29 · GPT-6.1 Sol in ChatGPT Work and Codex. OpenAI began rolling out GPT-6.1 Sol for agentic coding, computer use, and professional work. It gives desktop Codex users a new model option, subject to plan and workspace availability.

September 29 · Dots in the ChatGPT desktop app. Eligible users can create always-on agents in the desktop app. A dot has a goal, connected apps, and its own cloud computer, so this is a meaningful shift from one-off chats to persistent delegated work.

September 29 · Meetings plugin for macOS. The beta macOS desktop app can take meeting notes and save personalized summaries with action items to Space. Audio is deleted after the notes are prepared, which is the key operational privacy boundary.

September 29 · Space and Code Review on desktop. Space is available in the desktop app for eligible plans, and Code Review is available through a plugin on supported desktop experiences. Together they make the desktop app more useful for keeping project material close to conversation and reviewing pull requests in-context.
