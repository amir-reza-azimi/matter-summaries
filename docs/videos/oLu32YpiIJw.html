My AI Design Workflow That Doesn't Ship Slop

Channel: Greg Isenberg · Published: 2026-06-30 · Length: 51 min · Watch on YouTube

Designer Mangto (creator of the design tool Aura) explains design.md — an emerging open-source convention, the visual-design equivalent of agents.md or skill.md — a structured markdown file capturing a design system's colors, typography, spacing, and (for richer implementations) WebGL/3D animation rules, which you attach to a prompt so an AI tool applies a consistent visual identity rather than inventing a new look every time.

The problem it solves is described as "design drift": you one-shot a beautiful first screen, then every subsequent page or section drifts toward something more generic, because the AI has no persistent memory of the design decisions that made the first screen work. Design.md fixes this by giving the agent a portable recipe — HTML is the finished dish, design.md is the recipe, and skills are the ingredients — that carries the same DNA across completely different output mediums: a landing page, a slide deck, a promo video, mobile layouts, all generated from the same underlying tokens.

The setup workflow starts with remix-based exploration in tools like Variant or Aura's community gallery: browse existing designs, click remix repeatedly, and converge on a style you like before extracting its design.md and often its companion HTML file (design.md alone doesn't always capture animation or WebGL, so downloading both together preserves the full recipe). From there, skills are layered on top — reusable prompts for specific effects (a "laser" skill, a skeuomorphic-design skill mimicking pre-flat-design Apple realism, a 3D-globe skill) that function as the differentiator once a design system's baseline typography and color palette are no longer enough to stand out on their own, since the overall quality bar across the industry has risen so fast that yesterday's "wow" (a purple gradient, for instance) now reads as an instant signal to leave a page.

The core discipline Mangto stresses repeatedly is iteration over one-shotting: across four products he's building simultaneously, he estimates using well over a thousand prompts per product rather than expecting a single generation to be final, treating each pass as either a small iteration (used roughly 90% of the time, for refining something already working) or a full remix (roughly 10% of the time, for building an entirely new product category). The reason this matters for taste specifically: a design system captured once in a design.md file can be carried across tools — Aura to Figma to Codex to Cursor — meaning the thousand-iteration investment compounds instead of resetting every time you switch platforms, and can be committed to an agent's memory so it's simply recalled rather than re-explained each session.

A live demo walks through generating a landing page for a fictional product using a downloaded design.md plus HTML pair, then progressively adding sections (a footer, mobile variants, a slide-deck version, a motion-design version) from the same design tokens — with a copywriting skill layered on top to improve the generated text specifically. The same demo is repeated in Google Stitch to show design.md isn't tool-specific: attaching the same file there reproduces a comparably consistent output.

The closing argument is about where value actually sits now that anyone can one-shot a product: taste. Concretely, that means being deliberately surrounded by good design (following makers and creators in your niche, studying every app in your category), making fast, confident micro-decisions about what looks right, and recognizing that most competitive advantage today comes from being early to new tools and techniques rather than from technical skill alone, since the technical part is increasingly commoditized. A closing recommendation worth building into a personal workflow: keep a "second brain for design inspiration" the same way you'd keep one for notes or ideas — capturing real-world and digital design moments as reference material for future work, not just for notes and meeting content.

The design.md pattern is directly applicable to Amir's marketing and personal-brand work (LinkedIn, Pursuit newsletter visuals) as a way to keep AI-generated assets consistently on-brand across formats without re-specifying the visual identity each time, and pairs naturally with the same design-token idea covered independently this week in Simon Scrapes' carousel-generator video.
