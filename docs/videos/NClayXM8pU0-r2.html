Give ChatGPT and Claude the Same Memory

Channel: Nate Herk · Published: 2026-08-06 · Length: 1 min · Watch on YouTube

TL;DR

The video demonstrates a portable memory service that lets several AI systems access selected context. Instead of rebuilding preferences, project facts, and prior decisions inside every new chat, it proposes a separate memory layer that can be shared selectively across tools.

What the demonstration shows

The workflow is simple. Create an account, connect Claude, and ask it to remember something. Open ChatGPT afterwards, ask a related question, and it can use the previously stored information. The claim is that the context is not trapped inside one provider's chat history. Claude, ChatGPT, and other agents can work from the same baseline rather than forcing the user to repeat themselves.

That matters because ordinary chat history is convenient but provider-bound. It may be hard to inspect, difficult to correct, and subject to unclear retention rules. A portable layer creates the possibility that information about a person or project lives somewhere separate from the model that happens to use it today.

The evaluation criteria

The clip describes the memory as encrypted and user-controlled, with access decided model by model. Those claims need verification before adoption, but they define the correct bar. Shared memory should be visible, editable, and revocable. It should show which facts are stored, which tool can access them, and what happens when a fact is deleted or changes.

It should also be compared with the existing file-based approach. The vault is portable, versionable, and readable by a human. A hosted memory layer may reduce setup friction and make retrieval smoother, but it introduces another service, permission boundary, and potential lock-in point.

Why this matters for my work

For Amir's personal operating system, the question is whether cross-model continuity improves without weakening ownership or inspectability. For client work, it is a concrete example of the difference between isolated AI chats and shared context architecture. I could trial it with non-sensitive facts, test it across models, and keep the vault as the source of truth.
