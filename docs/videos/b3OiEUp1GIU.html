Claude Cowork Just Went Fully Hands-Off (Scheduled Tasks V2)

Channel: Simon Scrapes · Published: 2026-07-20 · Length: 16 min · Watch on YouTube

TL;DR

Anthropic's Cowork update lets Claude scheduled tasks run entirely inside Anthropic's own cloud, with zero server setup required. Simon Scrapes live-builds a monthly subscription-and-expense audit from a single plain-English prompt, showing how a solo business owner can replace a maintained VPS or an N8N-style workflow build with little more than a five-minute conversation.

Walkthrough

The video opens with the pain point directly: before this release, getting a recurring AI-powered task to run meant choosing between three unsatisfying paths. Local scheduled tasks inside the desktop app worked, but only while your laptop stayed open and awake, which meant deliberately forcing the lid to stay up. Claude's managed agents were the developer route: powerful, but you were setting up credential vaults and GitHub repos, which most business owners have zero interest in touching. And renting a VPS to run Claude Code yourself, which Simon had actually done in an earlier video, meant wiring up tmux sessions and a Telegram bot just to check in remotely, and then maintaining that server indefinitely. The new release removes all three: you describe the task, pick a frequency, and it runs on Anthropic's infrastructure, billed against your existing Pro, Max, Team, or Enterprise plan rather than as separate metered usage.

He walks through the two automations he already has running. The first is a weekly invoice and receipt reconciliation job: every Friday at 4pm, Claude scans roughly 600 transactions in his accounting software (Free Agent), searches three separate inboxes for the matching receipt, and attaches it automatically, closing out a task that used to pile up for a painful year-end scramble. The second is month-end financial reporting, replacing a manual routine of exporting bank transactions into a spreadsheet, dragging down formulas, and building a P&L tab by hand. Because both are functions every business needs, he turned them into shareable skills that interview the user about their own tools and spreadsheets and build a bespoke version of the same workflow. Total build time for both was about four hours, and most of that wasn't spent building at all — it was answering Claude's clarifying questions and reviewing the test runs it generated on its own.

Then comes the live build: a third automation, a monthly subscription and recurring-bill audit. Free Agent isn't one of the built-in connectors, so he'd already had Claude build and host a small MCP server against Free Agent's developer API to bridge the gap — adapting a public repo and adding upload/receipt-matching functionality himself. For anything else missing from the native connector list, he points to Composio as the fallback: a marketplace of roughly 147 app integrations with a free tier covering 20,000 requests a month, useful for cases like wiring up multiple Gmail inboxes through a single MCP connection with one-click OAuth. From there the actual task description is almost trivially short: pull recurring bills and expenses, compare each to the prior month, flag price increases, duplicates, and anything untouched for six months, and email the results on the first of the month. Before scheduling anything live, Claude runs the task retrospectively against real historical data and iterates on its own prompt until a test run looks right — a meaningful trust step before it goes unattended.

Standout moments

The finished audit is a good demonstration of why this is worth doing monthly rather than once: overall spend was up 15%, but the increase traced almost entirely to a Meta ad-spend bump rather than subscription creep. Buried underneath that, though, the audit still caught four subscriptions with real price increases (an added seat on one tool, a 30%-and-climbing Slack bill, a 20% jump on Airtable), three overlapping AI-assistant subscriptions, and four separate infrastructure providers all billing in parallel — exactly the kind of slow subscription sprawl nobody remembers to check by hand every month.

The limitations section is unusually candid for this kind of video. Cloud scheduled tasks can't reach local files at all, so anything that genuinely needs a folder on your laptop still has to run locally, which defeats the point of moving it to the cloud in the first place. And you can't store raw credentials or API keys in the task, either as a connector configuration or pasted into the prompt body — you're limited to the built-in OAuth connectors or something like Composio standing in front of them, with real environment-variable support reserved for the more technical managed-agents product.

Why this matters for my work

This is the exact pattern the vault already runs on — this digest itself is a Cowork scheduled task — so the video is a useful gut-check on what's now trivial to schedule in the cloud versus what still needs the heavier managed-agents route, and the Composio detail is a concrete answer for wiring up apps that don't have a native Claude connector. For the 10x Operator course, the "audit an annoying task, turn it into a skill, schedule it" arc demoed here, four hours end to end and mostly spent answering questions rather than building, is close to a ready-made module: a non-technical business owner's first cloud-scheduled Claude automation in a single afternoon.
