Anthropic Just Solved Claude Cowork's Biggest Limitation (Goodbye MCP)

Channel: Simon Scrapes · Published: 2026-07-22 · Length: 13 min · Watch on YouTube

TL;DR: Claude Cowork has a new feature called Record a Skill: you screen-record yourself doing a task once, narrating your reasoning as you go, and Claude turns that recording into a repeatable skill it can run on its own afterward, on any software, with no API and no MCP connection needed. If you can click through it on screen, you can now teach Claude to do it.

Why this matters more than it sounds. Every automation approach up to now has needed either an API or an MCP connector on the other end. That means any tool without one, an old enterprise system, a niche SaaS product, a scrappy no-code tool like ManyChat, has simply been untouchable by AI. Record a Skill removes that requirement entirely. You're no longer the bottleneck standing between a process you know and a process Claude can run, because you don't need a developer to build a connector first, you just need to be able to demonstrate the task once.

The live demo: an Instagram DM lead-magnet automation. Simon runs a classic lead-magnet loop on Instagram: post a short, ask viewers to comment a keyword, then use ManyChat to auto-DM them a link once they follow. ManyChat has no API and no MCP, so until now this had to be redone by hand for every single video he uploaded, which is a pain especially when posts are scheduled to go live while he's not watching. All the context Claude needs already lives in a Notion table (the video transcript, the ManyChat keyword, the Instagram video and thumbnail, whether the automation is already live), but nothing had ever been able to actually operate the ManyChat interface on his behalf.

Recording the skill. Inside Claude Cowork's desktop app (Mac only for now), he opens Record a Skill, which captures his screen, clicks, typing, and voice simultaneously. As he works through the real process, duplicating an existing ManyChat automation, renaming it to the new keyword, picking the correct Instagram reel, pasting in the video link, and pushing it live, he talks out loud about what he's doing and why. The recording captured 61 discrete steps from about four minutes of him narrating the task once. Claude then asked clarifying questions based on what it observed: should it also mark the Notion row as live once the automation goes live (yes), and what were the downloaded video and thumbnail files actually for, since he never used them in the ManyChat steps (a mistake on his part, left over from a different process). It caught things he'd gotten wrong or forgotten to mention himself.

Testing the skill on a new video. To prove it wasn't just replaying the exact steps it had seen, Simon deleted the automation and asked Claude, now equipped with the saved skill, to do it again from scratch for a different video and a different keyword. Using Claude's Chrome integration, it opened the browser, found the correct Notion row, downloaded the right thumbnail, navigated into ManyChat, duplicated the correct automation, typed in the new keyword, matched the new video by title rather than defaulting to 'just pick the latest,' pulled the new YouTube link from Notion, saved it, and pushed the automation live, all visibly, screenshot by screenshot, inside the actual browser window. It even proposed turning the whole thing into a scheduled task: check daily for a new YouTube video, and if there is one, run the ManyChat automation for it automatically.

Standout moment: Simon's own framing of who should use this first: 'just think about the tasks that you do every day that have a custom portal or admin screen or tool that nobody's ever built that MCP for, those are the ones that you should target with this first.' That's the real unlock, not the flashy demo, but the long tail of internal, custom, or niche tools every business runs that were previously off-limits to automation entirely.

Why this matters for my work: this is a direct answer to the exact wall that keeps coming up when teaching non-technical operators to automate, that so many of the tools a business actually runs on (industry-specific portals, legacy internal systems, scrappy SaaS with no API) have never had and will never get a proper integration built for them. Record a Skill means the course material and consulting engagements can stop starting from 'first, check if this tool has an API' and instead start from 'show me how you do it once, on camera, talking through your reasoning,' which is a dramatically lower bar for the non-technical business owners this is built for. It's also a concrete new tool to bring into Ranger AI engagements for exactly the custom, un-integrated systems that show up in nearly every client's stack.
