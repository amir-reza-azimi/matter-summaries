# Public publication boundary

This repository and every committed file are PUBLIC, including data/, commit
messages, Git history, and files outside docs/. Treat it only as a host for
summaries of verified public sources.

Never add personal profiles, journals, private correspondence, health or financial
records, itineraries, reading preferences, annotations, account IDs, internal work,
credentials, tokenized links, local paths, or private relevance/application notes.
Do not write personalized "for the reader" paragraphs. Keep private inputs and
automation state outside this checkout. Unknown sensitivity means stop publishing.

Before any publishing work, read PRIVACY.md and run the hook installer. Never
disable hooks, bypass a privacy failure, approve files without reading them, or use
API/web uploads to evade the gate. A missing private identity policy blocks work.

Review every changed content file against its public sources. Record exact-byte
review receipts using privacy_guard.py review. Scan the complete staged tree and
every outgoing commit before pushing. Use a generic publication author and GitHub
noreply email. New clones require hook installation and a private identity policy.

Protective code is not an absolute confidentiality guarantee. Local hooks can be
bypassed and do not govern other clones, web edits, or API writes. Do not claim
server-side prevention or historical erasure. Never rewrite remote history without
explicit authorization.
